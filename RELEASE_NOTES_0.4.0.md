# Release Notes 0.4.0

Version 0.4.0 turns the evidence contract into an operationally bounded product.
It adds a private Windows SIP collector runtime, DPAPI credentials, scheduling,
recovery, quality evaluation, a public-data firewall, and a React observatory.

The release does not start formal Data Shadow, estimate a current market model,
create a paper position, or create a real order. Day 0B remains a redacted,
partial rehearsal that does not count toward the 20-day gate.
