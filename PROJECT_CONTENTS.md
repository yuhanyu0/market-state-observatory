# Project Contents

Market State Observatory 0.4.0 is a standalone, public-safe evidence-state
research system.

## Stable core

- Point-in-time Observation and lineage contracts
- Independent observer registry and structured disagreement
- Evidence graph, response mode, next probe, and State Certificate compiler
- Direction -> Transmission -> Episode -> Playbook -> Vehicle state chain
- Five stateful playbooks with Model Shadow boundaries
- Vite + React + TypeScript product and synthetic reference corpus
- Schema, secret, publication, link, and manifest validation

## Integration boundaries

- Redacted Alpaca rehearsal summary bridge
- Private Alpaca SIP data-only runtime and Windows scheduler
- Public-data projection, manifest, worktree, and Pages pipeline
- Public State Certificate bridge
- Theme Radar structural-attention observer contract

## Experimental and removable

- Graph state-space models
- PDE and boundary-dependent field models
- semantic and event observers

All three are disabled under `labs/` and are not imported by the default
pipeline.

## Explicitly excluded

- credentials and account data
- raw provider responses
- private Data Shadow or Model Shadow runs
- paper positions, paper orders, and real orders
- modifications to `yuhanyu0/theme-radar-log`
