# Market State Observatory 0.5.0-rc1

This release candidate introduces the Observation-to-Decision Foundation without activating a new capture runtime.

## Included

- Deterministic completed-run feature/provenance/quality ledgers.
- Private JSON, Markdown, and HTML observation reports.
- Append-only sanitized WebSocket connection-event evidence.
- Frozen D0/D1/D2 Direction, Transmission, E0/E1 Episode, and E2 plugin candidates.
- Candidate observer conflicts, NextProbe, state certificates, Fragility, playbooks, and vehicles.
- Strict replay experiment registry and walk-forward utilities.
- Localhost-only multi-page Operator Console.
- Read-only `MSO-Daily-Report` sidecar and reviewed `-WhatIf` installer.
- Strict schemas and the compact 2026-08-18 acceptance fixture.

## Not Authorized

- Formal Data Shadow creation.
- Model Shadow without a separate valid promotion artifact.
- Any paper or live position.
- Any real order.
- Candidate output described as calibrated or validated.

The active `v0.4.5` release, experiment lane, Scheduler action, and completed runtime evidence remain unchanged.
