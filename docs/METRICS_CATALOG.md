# Metrics catalog

## Direction

Expected absolute/relative return, positive-sign probability, downside quantile, calibration error, uncertainty.

## Transmission

Breadth, median residual, ETF/basket agreement, volume breadth, propagation, concentration, graph coherence.

## Episode

Change probability, run length, state persistence, transition confusion, state-conditioned outcomes.

## Playbook

Coverage, net return, maximum drawdown, CVaR, turnover, false-entry rate, invalidation timing.

## Observer disagreement

Conflict frequency, lead/lag, conditional volatility, conditional return, resolution time.

## Publication and data

Observation success, quote age, missingness, future timestamps, backfills, membership coverage, public audit findings.
