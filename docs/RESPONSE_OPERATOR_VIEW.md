# Response-operator view

The deepest project object is a market response operator: how shocks map into signed, distributed and time-dependent asset responses.

```text
shock / information / flow
        ↓ response operator
asset-level impact, propagation, persistence and fragility
```

Direction estimates sign and magnitude. Transmission estimates spatial support. Episode estimates temporal phase. A playbook is a control policy conditioned on these response properties.

This view connects the project to broader mechanism-identifiability research: a compact state is valuable only if it preserves future response and action rankings across relevant boundaries.
