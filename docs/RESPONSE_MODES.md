# Response modes

A response mode is a dynamic loading pattern over assets:

```text
shock / event / flow
        ↓
shared market response
        ↓
asset support + sign + propagation
        ↓
semantic labels
```

This prevents broad labels such as `Semiconductors` from being permanently compressed into a single high-beta stock. The same semantic theme may contain several response modes, and the same response mode may cross semantic boundaries.

Future estimators may use transparent factor models, Graph SSM, Koopman observables, field/PDE representations or other encoders. They are evaluated by whether they recover stable decision-relevant structure, not by architectural prestige.
