# Transmission

Transmission asks whether a response propagates through a theme. It uses ETF and
basket agreement, constituent residual breadth, median constituent response,
volume breadth, leader-to-rest propagation, single-name concentration, and
dynamic coherence when legally available.

States are `broad_confirmed`, `narrow_only`, `absent`, and
`negative_coherence`. Data readiness means the inputs exist; it does not mean
broad propagation was observed. Historical Transmission is unavailable when
point-in-time membership is unavailable. Current constituents must never be used
to fill a historical basket.

Transmission remains only if same-date ablation improves Direction reliability
in untouched test windows after costs.
