# Project Thesis

The primitive object is not a theme name, score, or trade. It is a response
structure: how information or flow propagates across assets, with what sign,
support, speed, fragility, and uncertainty.

A semantic theme is a prior over a region of that structure. Direction estimates
signed release. Transmission estimates support and propagation. Episode locates
onset, expansion, retest, maturity, exhaustion, or reversal. Playbook selects a
stateful research option. Vehicle expresses that option only after the state is
decision-sufficient.

Theme Radar can add information as a structural-attention observer without being
a bullish signal. Observer disagreement is therefore first-class evidence. The
system asks which next point-in-time probe best distinguishes candidate states,
and it prefers an explicit no-decision state to invented certainty.
