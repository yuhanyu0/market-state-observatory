# Pruning guide

The scaffold is intentionally broad so that unnecessary pieces can be removed later.

## Core — keep unless the project thesis changes

- Observation and State Certificate schemas;
- facts / inference / action separation;
- evidence grades;
- public/private boundary;
- Data Shadow and Model Shadow distinction;
- observer disagreement;
- no-secret publication audit.

## Strongly useful but removable

- active next-probe logic;
- response-mode abstraction;
- A/B/D/F playbook layer;
- Theme Radar external-observer integration;
- research agenda pages.

## Experimental

- automated VOI estimation;
- Graph SSM and PDE/field encoders;
- equal-risk torque overlay;
- LLM narrative rendering;
- public live status automation.

Remove experimental modules by deleting their observer/publisher integration, not by weakening the evidence contract.
