# Reflexive memory

Reflexive memory records why a state was assigned, which action was considered, what evidence invalidated or confirmed it, and what outcome followed.

It does not automatically rewrite frozen hypotheses. Updates are proposed through a versioned review process:

1. collect prospective outcomes;
2. identify systematic error by observer or playbook;
3. propose a threshold/model change;
4. freeze a new version;
5. test it on future untouched windows.

The memory layer is therefore an audit and learning system, not an excuse for continuous in-sample tuning.
