# Evidence model

## Evidence grades

1. `synthetic_demo`
2. `historical_reconstructed`
3. `commit_anchored_unverified_inputs`
4. `prospective_data_shadow`
5. `prospective_model_shadow`
6. `micro_live_observed`

A lower grade cannot be promoted by writing a more confident narrative.

## Required distinctions

- **Existence:** did the file or signal exist at the claimed time?
- **Input cutoff:** were all underlying inputs bounded by the decision time?
- **Execution identity:** was the price available at the intended action time?
- **Mapping identity:** did the theme/vehicle definition exist then?
- **Independence:** how many genuinely distinct episodes or events exist?

## Negative evidence

`no_trade`, `not_estimable`, `observer_conflict` and `missing_observation` are first-class outcomes, not pipeline failures to hide.
