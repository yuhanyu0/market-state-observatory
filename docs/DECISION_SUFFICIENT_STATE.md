# Decision-Sufficient State

A state is decision-sufficient only when the required evidence is available,
estimated, eligible, mutually coherent enough for the intended playbook, and
accompanied by explicit invalidation. `data_ready` alone is not sufficient.

For a positive theme-level research option, the first contract requires signed
positive Direction, broad-confirmed Transmission, an estimable Episode,
non-blocked Fragility, and a supported A or B playbook state. The public system
still emits only `MODEL_SHADOW_ONLY` unless a separately preregistered validation
gate authorizes a later status.

Missing inputs produce `DATA_BLOCKED_NO_DECISION`. Ambiguous sign, absent
Transmission, negative Direction, exhaustion, or blocking Fragility produce
`WAIT` or `NoScript`. The project never labels these outcomes as evidence that
cash was optimal after the fact.
