# Architecture

```text
Point-in-time observations
  -> Independent observers
  -> Evidence graph
  -> Response-mode estimate
  -> Decision-sufficient state
  -> State Certificate
  -> Stateful playbook option
  -> Shadow outcome
  -> Reflexive memory
```

## One truth per layer

Observation owns facts and lineage. It may report missing data but cannot infer
Direction. Observer estimates are independent and expose uncertainty and
invalidation. The evidence graph retains support and contradiction. Response
mode describes sign, support, propagation, lifecycle, and fragility without
assuming the semantic theme is the primitive object.

The State Certificate combines facts and inference without erasing their type
boundary. A playbook is a control option with prior state, activation,
invalidation, and termination. Vehicle choice follows the playbook; torque is a
risk-normalized overlay, not a fixed story-stock mapping.

Theme Radar observes structural attention only. An LLM can render an already
validated certificate but cannot create facts or alter eligibility. Every added
layer must earn retention through same-date incremental ablation.
