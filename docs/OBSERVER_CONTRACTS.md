# Observer contracts

Every observer emits an `ObserverEstimate` and must declare:

- target question;
- point-in-time input contract;
- output state space;
- uncertainty;
- evidence references;
- invalidation;
- validation metric;
- failure mode.

## Direction

Target: signed absolute and relative future return distributions.

## Transmission

Target: whether direction is broad, narrow, absent or negatively coherent.

## Episode

Target: response-mode lifecycle state, not merely repeated theme labels.

## Theme Radar structural attention

Target: structural importance, attention migration or activation. It cannot directly set Direction labels or trade gates.

## Fragility

Target: gap, spread, liquidity, concentration, volatility and boundary risk.

## Event / semantic

Target: what changed in the world, with explicit `known_at` provenance. Event date alone is insufficient.
