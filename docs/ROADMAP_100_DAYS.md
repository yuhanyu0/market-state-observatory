# 100-Day Roadmap

## Days 1-20: measurement integrity

Run point-in-time Data Shadow only. Require complete core ETF coverage, quote
freshness, no future timestamps, no backfill, immutable lineage, and public-safe
daily quality summaries. Do not make model decisions.

## Days 21-40: transparent Direction

Freeze and calibrate the transparent signed Direction baseline. Compare it with
simple momentum on the same dates using walk-forward evaluation. Audit theme and
date concentration. Keep Transmission and Episode informational until their data
and ablations qualify.

## Days 41-60: incremental state layers

Evaluate Transmission on point-in-time memberships, then Episode on legal
sequential history. Each layer must beat the preceding stack on untouched dates
and retain uncertainty and invalidation.

## Days 61-80: stateful playbooks

Run Model Shadow for A, B, D, F, and NoScript. Compare fixed holding with the
state machine after costs. No live actions.

## Days 81-100: vehicle and publication review

Test ETF, Basket, and equal-risk overlay ablations. Review product surfaces,
security, public evidence, and pruning candidates. A later micro-live proposal is
possible only through a new preregistered risk and governance gate.
