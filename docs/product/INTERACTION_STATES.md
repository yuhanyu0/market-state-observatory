# Interaction States

## Loading

The shell shows fixed-size skeletons and `aria-busy=true`. No previous state is
presented as current while a request is pending.

## Ready

Filters update comparable public state only. Theme and certificate routes are
permalinkable. JSON/CSV downloads contain public derived data.

## Blocked

The page names the blocking input or evidence gate. `data_ready=true` cannot
produce positive/negative Direction copy without `model_estimated=true`.

## Failure

The app shows the failed public resource class and a retry command. It does not
fall back to embedded stale private or provider data.

## Evidence drawer

Opening moves focus to Close. Escape and backdrop click close it. The drawer
exposes lineage without mutating the certificate.
