# Accessibility

- Semantic headings, navigation, tables, lists, definitions, and dialogs.
- A skip link bypasses navigation and global filters.
- All commands are keyboard reachable; focus uses a visible 3 px outline.
- Evidence drawer supports Escape and receives initial focus.
- Status always includes text and shape in addition to color.
- Minimum control height is 32 px desktop and mobile navigation is 62 px.
- `prefers-reduced-motion` disables nonessential animation.
- Certificate pages have a print stylesheet suitable for PDF output.

Release checks include keyboard traversal at desktop and mobile widths, text
overflow, zoom resilience, dialog semantics, and serious accessibility errors.
