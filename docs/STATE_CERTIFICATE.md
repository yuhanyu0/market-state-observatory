# State Certificate

The State Certificate is the main public and internal interface.

## Required fields

- facts and provenance references;
- Direction;
- Transmission;
- Episode;
- structural attention;
- fragility;
- observer agreement;
- observer conflicts;
- uncertainty;
- invalidation;
- next probe;
- eligible playbooks;
- vehicle eligibility;
- decision status.

## Why / Why not / What changes the state

A readable certificate should answer:

1. Why is the current state assigned?
2. Why is confidence not stronger?
3. Which evidence would invalidate it?
4. Which next observation would most reduce decision uncertainty?
5. What action consequence follows, if any?

The LLM renderer may explain these fields but cannot edit them.
